# Momentos — Casa de Renta de Habitaciones

Sitio web de **Momentos**, casa de renta con piscina, billar, comida cubana, spa y servicios completos en **Pinar del Río, Cuba**.

**URL del sitio (GitHub Pages distingue mayúsculas):**
https://losramosdelrey.github.io/Momentos-de-Elizaberth/

## Estructura

```
index.html · habitaciones.html · servicios.html · contacto.html
en/        → versión en inglés
css/       → styles.css
js/        → script.js
libs/      → AOS, Font Awesome (subconjunto) y tipografías, alojados localmente
icons/     → íconos PWA
img/       → og-cover.jpg
images/    → fotos de testimonios
offline.html · 404.html · sw.js · manifest.json
sitemap.xml · robots.txt
```
